# 使用指南

## 1. 初始化和账号

部署人员提供 HTTPS 地址和初始化验证码（服务器 `.env` 的 `SETUP_TOKEN`）。打开 `/setup`，输入验证码、公司信息和管理员邮箱，自己设置至少10位且同时含字母和数字的密码。

完成后初始化入口关闭。后续用户由管理员在“设置 → 用户管理”添加，没有公众注册。管理员负责配置和授权，销售处理自己或获授权的客户，只读用户不能改资料或发消息。不要共享管理员账号。

## 2. 公司信息与 AI

在“设置 → 公司信息”配置公司、品牌、Logo、联系方式、签名和销售规则。保存后工作台品牌更新。

在“AI 模型”选择预设或自定义接口，填写 API Base URL、接口类型、模型名和自己的 API Key。模型名必须与服务商给你的权限一致；Chat Completions 和 Responses 按服务商说明选择，不能随意混用。

先测试连接，再单独测试流式输出、工具等能力；测试也会调用真实API，可能计费。可按对话、分析、翻译、视觉任务分配模型。客户AI附图交给当前对话模型，它必须支持图像输入；文本模型无法看图时换模型重试，系统不会假装识图。

你的 ChatGPT/Codex 订阅不等于 API 额度，历史对话也不会自动带进来。迁移见 [Codex 导入](CODEX_IMPORT.md)。

## 3. 先上传产品资料

在“资料库”按公司介绍、Logo、资质、产品系列、目录、图片、报价等建立文件夹，也可上传整个文件夹或ZIP。内部价格/工作文件与最终客户可发附件分开，选择正确的公司、内部或客户专属可见范围。

启用智能整理后，系统按内容提取、识别并归类，而不是仅按文件名猜测。扫描件/图片需要合适的视觉模型。上传成功不代表识别完成；处理失败、识别不清或低置信度文件保留待审核，先查看状态再使用。

以后在客户AI里说“找这款产品的目录和照片”，系统会检索已有的获授权资料，不用反复上传。发送前点击真实文件预览、核对版本。不要把供应成本、内部测算或无权限资料发给客户。

## 4. 录入邮件并跟进

1. 点“录入新咨询”，粘贴含发件人、主题和正文的邮件全文。
2. 核对自动识别的姓名、邮箱、公司、电话、国家和来源，可人工修改。
3. 后续邮件关联原客户；同一客户的新订单单独创建采购项目，不重复建档。
4. 在客户AI里说“总结进度，准备英文回复和中文对照，找到合适目录”。核对事实、价格、交期和附件，再编辑成草稿或复制到邮箱。
5. 生成草稿不等于已发送，人工标记也不是邮箱投递回执。项目里维护下一步、等待谁处理和跟进日期。

“全部客户 / 客户信息 / 客户 AI 助手”三栏可拖动或用方向键调整宽度；放大按钮单独展开，Esc恢复。浏览器记住你的布局，不修改客户资料。

## 5. 客户转到普通 WhatsApp

在“沟通”展开连接设置，阅读非官方连接风险并确认，再用普通 WhatsApp 的“已关联设备”扫码。手机、服务器和配置的代理都需网络可达；服务器代理不是在手机填写的代理。

聊天先进入管理员私有收件箱。选择业务聊天，关联原客户或确认建档；只有选定的业务聊天进入客户档案。平台隐私ID不能按数字猜测手机号，不同客户冲突不会自动合并。

- **消息**：点联系人查看客户来信和手机回复，按平台映射和消息ID归集、去重。
- **同步**：选聊天后“刷新”请求最近记录，“请求更早的平台记录”补较早记录。平台不保证全部历史可取回。
- **回复**：可先用客户AI准备文本，再核对收件人和内容，人工确认后发送。不确定是否发出时先查看手机，避免重复发送。
- **翻译**：每条消息可翻译，拟发草稿也可先翻译成目标语言。翻译不等于发送。
- **附件**：点文件名下载，单件最多50MB；已下载原件私有缓存。旧消息没有下载信息或媒体过期时，需要重新下发或客户重发。阅后即焚不保存，暂不支持发送附件/语音转写。
- **头像**：自动读取平台允许查看的头像，可手动重试；隐私和网络限制时保留占位图/已有缓存。

未关联私聊仅管理员可见，关联客户后按客户权限提供沟通和附件。非官方连接可能断线或账号受限，不用于群发、骚扰或绕过平台隐私。

## 6. 给 AI 发图片

Ctrl+V粘贴、拖入或点图片按钮选择文件。支持真实PNG/JPG/WebP，每条最多4张，单张最多8MB。预览后可移除；只有发送给AI时才交给当前服务商，不会发给客户。

图片按客户和采购项目隔离，提交后随对话保存，最近两条含图用户消息会继续进入多轮上下文，不是永久把所有历史图发给模型。手机不提供图片剪贴板时，使用按钮选择相册上传。

## 7. 来源表单与其他渠道

在设置创建来源入口，填写网站/广告等渠道、活动和负责人，把生成的咨询表单链接放到网站或广告；客户提交后形成带来源的档案。后端接入使用入口专用密钥，不把密钥放到公开前端代码。

WhatsApp链接仅打开聊天，不代表已收到咨询。客户真正发送、平台下发后才出现在收件箱，确认建档后成为CRM客户。

## 8. 备份

在“设置 → 备份恢复”生成并下载加密备份，妥善保存独立备份密码，并异地另存。GitHub代码不是业务数据备份。

恢复会先验证和暂存，重启时应用。先备份再恢复，不随意覆盖数据目录。完整备份与升级步骤见 [宝塔部署](../DEPLOY_BAOTA.md)。
