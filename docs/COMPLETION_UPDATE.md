# CRM 完善记录（2026-10-26）

本轮为现有版本的增量完善，不重新建库，不迁移私有本机数据。

## 新增与修复

- 客户授权可查看、撤销、转交；转交移除旧负责人的显式授权，保留客户记录。
- 自行改密码、管理员重置密码、停用或角色变更会撤销该账号全部旧会话。最后一位启用管理员不能被降级/停用。
- 双向真实沟通可驱动进度分析，草稿、未知发送结果、内部笔记不推进。进度建议带证据消息及项目版本，旧历史/并发人工编辑不会被旧结果覆盖。
- 安全自动跟进按项目自愿启用；产品/数量/目的地有新事实或冲突仍人工审核，自动建议不升级成已确认事实。
- WhatsApp可为多项目客户指定新消息默认采购项目；不自动批量移动历史记录。
- 每日加密备份默认关闭，启用后按北京时间执行、有后台检查和失败重试，展示真实结果。仍需自行异地保存。
- AI增加合成图像能力探测；上线清单区分配置状态和真实验收。能力探测须管理员手动触发，可能产生API费用。
- 修复异步表单成功后重置不稳定的问题、重复消息错误返回最后插入ID的问题。

## 验证方式与边界

构建和回归使用隔离临时数据、模拟服务，不使用真实客户/WhatsApp授权/API额度；详见`tests/`。增量数据库迁移保留既有记录。

仍需业务验收：各服务商真实模型权限、典型产品资料识别检索、真实WhatsApp双向收发/媒体与头像、小米15实机。网站/广告须实际放置生成的来源入口。并未承诺所有历史消息可回溯、所有头像可读取、完整Codex自动同步、自动异地备份或正式安全渗透测试。
